# IPL_dataset_analysis
IPL Dataset Analysis: Analyzed IPL match data using Python (NumPy, Pandas, Matplotlib, Plotly) and SQL queries to identify team, player, and match trends. Built an interactive Streamlit dashboard to visualize key insights and performance metrics.

IPL Dataset Analysis | Python, SQL & Streamlit

Performed an end-to-end IPL Dataset Analysis to uncover meaningful insights into team performance, player statistics, match outcomes, toss decisions, venues, and season-wise trends.

Tools & Technologies Used:

- Python: NumPy, Pandas
- Data Visualization: Matplotlib, Plotly
- SQL: SQL queries for data extraction, filtering, aggregation, joins, and analysis
- Streamlit: Developed an interactive dashboard to present analytical insights

Key Work:

- Cleaned, transformed, and explored IPL match data using Pandas and NumPy.
- Performed Exploratory Data Analysis (EDA) to identify patterns and trends.
- Used SQL queries to analyze match results, teams, players, toss decisions, venues, and performance metrics.
- Created visualizations using Matplotlib and Plotly for better understanding of the data.
- Built an interactive Streamlit dashboard to showcase key insights and analysis.
- Analyzed factors such as toss decisions, winning teams, match venues, season trends, and player/team performance.

Outcome:
This project strengthened my practical skills in Data Cleaning, EDA, SQL, Data Visualization, Python, and Dashboard Development, while demonstrating an end-to-end data analytics workflow.
